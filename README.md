## 1. 产品概述

**小岐药背汇**（谐音"要背会"）——**你的中医助手**，一款面向中医学生与考生的中药 / 方剂记忆工具。

- **一句话定位**：易混、易选错？要背会！
- **核心主张**：真正拉开选择题正确率差距的，不是排除三个错误选项，而是**最像的那两个（味药）能不能分清**。产品以「药对」为基本记忆单位，专盯最易混淆的药物，一对对辨析"焊死"。
- **产品形态**：移动优先的**无限流卡片**应用，像刷短视频一样背中药——不设结束节点，随时可以结束，也可以一直刷。
- **Slogan 体系**：
  - 背上瘾，不再是易混的、难背的
  - AI 生成无限流卡片，像刷短视频一样背中药

## 2. 背景与问题

| # | 痛点 | 描述 | 产品对策 |
|---|------|------|----------|
| 1 | **丢分在"二选一"** | 中药记忆点多、极易混淆；排除三个选项不难，真正失分发生在最像的两味药之间 | 以**药对**为单位背诵 + 刷题，共同功效打底、一句话区分点焊死 |
| 2 | **背不下去** | 背诵枯燥、正向激励少、缺即时反馈，背两天就放下 | **无限流卡片**：连续答对的爽感 + 做错即时推送辨析资料，形成正反馈 |

## 3. 目标用户与使用场景

- **目标用户**：中医学生 / 考生。
- **核心场景**：期末考试、执业医考试、考研中药、方剂复习、日常背诵。
- **使用特征**：以手机为主，**碎片化知识 × 碎片化时间**——排队、通勤、睡前，拿起手机随手刷几卡；不设结束节点，随时开始、随时结束。

## 4. 产品结构与信息架构

全屏卡片式导航，三层卡片 + 两个辅助页，共用同一条固定流动的暮色背景：

```
首页（章节卡 · 左右滑动）
  └─ 组卡学习页（药对组卡 · 左右滑动；上划进入小测）
        └─ 小测页（题卡 · 左右滑动；下滑返回组卡）
  └─ 我的页面（学习概览 + 复习 / 混淆清单入口）
        └─ 今日复习页（到期题卡 + 到期混淆对）

引导展示流（求职/介绍用，拼在章节卡之前，同一条发牌卡轨）
  8 张展示卡：Hero → 为什么做/怎么做(×2) → 为谁做/何场景
            → 在哪用 → AI 出卡 → AI 答疑与沉淀 → 关于我
  · 「立即体验」按钮：快速加速掠过展示卡，平滑停在第一章
  · 手势左右滑：自然滑过展示卡，无缝衔接正式章节
```

## 5. 功能需求

### 5.1 卡片式学习主流程 🟢

| 模块 | 说明 |
|------|------|
| **章节卡** | 首页左右滑动切换章节；展示章节名、药数、进度；点击进入组卡学习 |
| **组卡（药对辨析卡）** | 一组 2 味（或多味）易混药：顶部「共同功效条」→ 组内各药（药名 + 一句话区分点 + 星标特殊功效 + 要点列表）；卡内长内容可原生滚动 |
| **小测（题卡）** | 组卡上划进入；题干 + 4 选项；作答后即时反馈对错；底部「这俩我分不清」按钮 |
| **两药区分卡** 🟡 | 点"分不清"后，把两味药发后端，返回对比辨析（共同功效 / 一句话区分 / 记忆钩子 / 变式题） |

### 5.2 记忆机制 🟢 / 🟡

- **混淆对焊死（间隔重复）** 🟢：答错或点"分不清"的两味药结成「混淆对」，按 **1 / 2 / 4 / 7 / 15 / 21 天**节点各复习一次；第 21 天答对即"焊死"；任一环节答错，周期从次日重新计。
- **题级掌握度（防蒙抽检）** 🟢：答对不立刻算掌握，首次答对后按 **1 / 3 / 7 天**随机回来抽检，3 次全对才算掌握；抽检中答错则归零重来。
- **错题三分类归因** 🟢：选项在出题时标定角色 tag，答错自动归因：
  - `confuse` 组内混淆（选了最像的那味药）——自动提炼混淆对
  - `unrelated` 完全不会（选了组外干扰项）
  - `concept` 概念错误（功效归纳类）
- **防蒙乱序** 🟢：选项随机排序，不靠位置记忆。
- **今日复习** 🟢：到期题卡 + 到期混淆对聚合到复习流；首页复习按钮带到期角标。
- **混淆清单 / 我的页面入口** 🟡：列表页目前为占位 toast，待开发。

### 5.3 无限流与 AI 能力 🟡 / ⚪

预置卡片刷完后，AI 接力生成后续卡片，**不设结束节点**。

- **出什么——看用户状态**：结合错题情况、混淆情况、是否需要回忆（到期抽检）。
- **怎么生成**：
  1. **推荐算法排序**：按薄弱点排出最该先生成的内容 🟡
  2. **基于数据库（事实库）生成卡片**：题干 / 选项 / 答案基于中药事实库，知识点锁死，AI 不瞎编 🟡
  3. **基于知识图谱生成答疑**：点"分不清"时沿知识图谱即时讲解两药差异 🟡
- **质量兜底** ⚪：AI 生成 → **人工审核** → 进入卡片库，错误内容不进用户卡片流。
- **沉淀**：刷过的错题 / 混淆对回流推荐流，越刷越对准个人薄弱点 🟡。

### 5.4 触达与入口 ⚪

- **三种打开方式**：微信小程序（免安装、主入口）、手机网页（可"加到主屏幕"，PWA）、App（规划中）。
- **到点提醒**：① 微信服务通知（主，到期复习时推送，点开直接进卡片）；② 手机桌面横幅（PWA 为辅）；仅在真有到期复习时提醒，不轰炸、可关闭。

## 6. 内容与数据模型

内容层级：**章节 Chapter → 组卡 GroupCard（药对）→ 药 Herb → 题 Quiz**。

```ts
// 卡片来源：预置人工录入 / 模板规则生成 / AI 生成
type CardSource = 'preset' | 'template' | 'ai';

interface Herb { name: string; diff: string; star?: string; points?: string[] }
interface GroupCard { id; title; common /*共同功效*/; herbs: Herb[]; source?: CardSource }

// 选项角色 tag：出题方标定，不对用户显示，仅用于答错归因
type OptionKind = 'answer' | 'confuser' /*易混干扰*/ | 'distractor' /*不相干干扰*/;
interface QuizOption { key; text; herb?; kind: OptionKind }

// 题型：单药识别 / 药对辨析 / 共同功效概念 / 用法 / 跨组综合
type QuestionType = 'identify' | 'distinction' | 'concept' | 'usage' | 'cross';
interface Quiz {
  id; groupId?; questionType; question;
  options: QuizOption[]; answer; answerHerb?; involvedHerbs?; source: CardSource;
}
```

- **学习数据本地存储**（localStorage，免登录）：混淆对 `ConfusePair`、作答记录 `AnswerRecord`（只记错题）、题级掌握度 `QuizMastery`。
- **内容扩充方式**：人工在 `src/data.ts` 按 `groups[]` / `quizzes[]` 结构录入；也支持电子版笔记文件批量导入。事实内容以纸质笔记 / 权威教材校对为准。

## 7. 交互与视觉规范（摘要）

- **移动优先**：内容最大宽 480px 居中，桌面端两侧留氛围背景；不做多栏布局。
- **发牌手感（核心动效）**：横向卡轨上当前卡摆正，两侧邻卡微斜（±5°、scale .94）、远卡淡出（±8°、scale .9）；卡间留缝隙，像一叠牌；滑到哪张哪张"摆正"。整页翻页同理（从下方带 2° 微斜发入再摆正）。
- **背景固定**：紫粉暮色渐变 + 光晕缓慢流动，永远 fixed，不随任何翻页位移。
- **分层阅读原则**：玻璃 / 渐变只做"氛围壳"（背景、光晕、圆按钮）；承载阅读的组卡 / 题卡 / 弹窗用高不透明**暖白纸卡 + 深墨字**，保证长时间盯读的可读性。
- **手势**：左右滑动切卡、组卡上划进小测、题卡下滑返回；卡内长内容走原生滚动；轴判定带滞后阈值，避免"想滚内容误判翻页"。

> 完整设计规范见 [DESIGN.md](./DESIGN.md)。

## 8. 技术架构

- **前端**：Vite 7 + 原生 TypeScript（无框架）+ Tailwind CSS 3；自研手势 / 卡轨 / 发牌动画引擎（`src/swipe.ts`）。
- **后端**：Express + TypeScript；中药事实库 `server/herbDb.ts`；预留 AI 生成接口。
- **数据 / AI**：Supabase（数据持久化规划）、大模型 SDK（卡片与答疑生成，事实层由 `herbDb` 锁死）。
- **存储**：当前学习进度走 localStorage；后续云端同步 + 登录体系。
- **包管理**：pnpm（强制）。

### 主要后端接口（已预留）

| 接口 | 方法 | 说明 |
|------|------|------|
| `/api/feed/next` | POST | 无限流拉下一批卡片；入参带用户画像（活跃混淆对、错题分布、薄弱药、已学组等），返回题卡 / 组卡 |
| `/api/distinguish` | POST | 两药区分卡；入参两味药 + 上下文，返回共同功效 / 一句话区分 / 记忆钩子 / 变式题 |

## 9. 合规与提示

- 本产品为**学习记忆辅助工具**，卡片内容、答疑与讲解由 **AI 生成并经人工抽检**，可能存在疏漏。
- 知识点以**权威教材与考纲为准**；内容**不构成诊疗建议 / 医嘱**。
- AI 生成内容须经人工审核方可进入卡片库。
